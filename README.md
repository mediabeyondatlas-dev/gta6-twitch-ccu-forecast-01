Forecasts GTA VI's launch-day Twitch viewers hour by hour (hours 2–24) from the case's own comparables: per-hour log ratios to the hour-1 print, grouped by opening size, with a log-size fit for large openings. Leave-one-out pinball loss 0.528 on the log scale vs 1.137 for the house starter. Python 3.13, standard library only.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
